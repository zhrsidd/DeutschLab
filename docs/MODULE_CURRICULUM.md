# Unit 1 module catalogue

Start: Sunday, 15 November 2026. These are authoring recipes, all planned; existing mapped lessons remain available. Module IDs are separate from persisted lesson IDs. The app does not yet run these recipes or track their completion.

All recipes inherit the [adaptive-practice contract](ADAPTIVE_PRACTICE.md): vary valid sentences and response modes, adapt to answer evidence and avoid recent repeats. The examples below name abilities and transfer goals, not a permanent fixed question list.
